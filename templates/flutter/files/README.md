# {{projectName}}

A Flutter app (Dart) for iOS and Android with strict static analysis, a widget test, CI, and Dependabot. Platform folders were generated by `flutter create`.

## Development

```sh
flutter pub get
flutter run
```

Point the app at your backend with `--dart-define`:

```sh
flutter run --dart-define=API_URL=http://10.0.2.2:3000
```

`10.0.2.2` is how the Android emulator reaches your computer; the iOS simulator can use `http://localhost:3000`. On a physical device, use your computer's LAN address.

## Verification

```sh
dart format .
flutter analyze
flutter test
```

## Notes

- The package ID is `com.example.{{dartName}}`. Change it before publishing.
- HTTP calls go through `lib/core/api_client.dart` (Dio).
- Never embed secrets in the app: anything shipped in a mobile binary can be extracted.
